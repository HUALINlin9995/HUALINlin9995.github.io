## 项目简介

项目名称：Python教程爬虫

开发环境：Python 3.11.7

开发语言：Python

库：requests、re、BeautifulSoup4、csv、queue、threading

项目类型：网页爬虫 / 数据采集工具

本项目用于爬取廖雪峰Python3教程，实现自动抓取目录、批量获取文章内容、保存为CSV文件、交互式操作等功能。

## 项目核心亮点

全自动爬取：自动解析网页结构，一键获取全部教程内容。

数据持久化：爬取内容自动保存为CSV文件，可随时查看。

交互操作：提供菜单式操作界面，无需修改代码即可使用。

异常处理：支持错误检测，内容不存在时自动提示，不崩溃。

编码安全：采用UTF-8编码，完美支持中文显示。

### 一、目录爬取功能

程序启动后首先爬取目标网站的所有教程目录，提取章节标题与对应URL，并保存为 thehttpd.csv 文件。

功能包含：

- 自动获取所有章节标题

- 自动拼接完整URL

- 过滤无效链接

### 二、单章内容爬取模块

根据传入的 URL，获取对应章节的正文内容，自动去除 HTML 标签，返回干净文本。
功能说明：

    发送 HTTP 请求获取页面内容

    使用 BeautifulSoup 解析正文区域

    提取纯文本，自动格式化换行
    支持异常捕获与超时处理

    不存在内容时返回提示信息

<img src="img/pachong/3.png" class="gallery-item">

#### 关键代码

```cpp
def requests_text(url):
    data = requests.get(url, timeout=10)
    soup = BeautifulSoup(data.text, 'html.parser')
    intro = soup.find('div', id='gsi-chapter-content')
    return intro.get_text(strip=True, separator='\n')
```

### 三、多线程并发爬取模块（核心功能）

通过 5 个线程同时爬取所有章节内容，使用队列分配任务，线程锁保证数据安全，最终统一写入 CSV 文件。

#### 功能说明:

    基于 Queue 任务队列实现任务分配

    5 线程并发执行，提升爬取效率

    线程锁保证数据写入不乱码、不错乱

    所有任务完成后统一保存文件

    实时显示爬取进度

    最终保存为 thedata.csv
