### 代码块示例

#### Python代码

```python
import requests
import json

def fetch_data(url):
    response = requests.get(url)
    if response.status_code == 200:
        return json.loads(response.text)
    return None
```

#### 使用提示

- **单击视频**：进入自定义全屏模式（保持宽高比）
- **双击视频**：使用浏览器原生全屏模式
- **ESC键**：退出全屏模式
- **全屏时**：视频不会拉伸，保持原有比例
