在学习了套接字（Socket）网络编程后，我一直在思考：能不能自己搭建服务器，写一个可以真正在公网上运行、别人下载后就能直接使用的即时通讯工具？

带着这个想法，我开始了QQ_LITE项目的开发

## 项目简介

项目名称：QQ_LITE

开发环境：Qt Creator 17.0.0

开发语言：C++

数据库：SQL Server

项目类型：仿QQ轻量级即时通讯客户端

本项目实现了一套完整的客户端/服务器通讯架构，支持账号注册、登录验证、实时聊天、断线重连、状态同步等核心功能，整体设计简洁、稳定、易用。

## 项目核心亮点

公网跨网络通讯：通过域名解析+端口映射，让客户端可以在外网直接连接服务器，不受局域网限制。
智能断线重连：网络断开时自动切换状态，并提供一键重连功能。
安全登录机制：密码加密显示，登录状态实时同步，提升使用安全性。
界面状态联动：网络状态、登录结果、操作提示全部实时反馈。
消息实时转发：登录成功后将Socket转交给主界面，保证消息不丢失、实时接收。

## 客户端功能与实现说明

### 一、登录界面

登录界面是整个软件的入口，我参考了QQ的经典布局，设计了简洁直观的登录窗口。

界面包含：
- 在线/离线状态实时显示
- 账号、密码输入框
- 忘记密码、注册、登录、取消功能按钮
- 网络异常时显示"重新连接"入口

<img src="img/QQ_LITE/denglu1.png" class="gallery-item">

#### 功能实现：域名解析与自动连接

为了让客户端能在外网稳定连接服务器，我没有使用固定IP，而是通过域名解析的方式动态获取服务器地址，避免服务器IP变动导致无法连接。

```cpp
QHostInfo::lookupHost(serverDomain, this, &master::onHostResolved);
```

同时通过信号槽监听连接状态，一旦网络断开，界面会自动切换状态提示，让用户清楚当前连接情况。

```cpp
// 连接成功/断开时同步UI状态
connect(socket, &QTcpSocket::connected, {
    isconnect=true;
    ui->stateyes->setVisible(true);
    ui->stateno->setVisible(false);
});
connect(socket, &QTcpSocket::disconnected, {
    isconnect=false;
    ui->stateyes->setVisible(false);
    ui->stateno->setVisible(true);
    ui->Reconnect->setVisible(true);
});
```

功能说明：
通过域名解析实现动态服务器定位，解决公网环境IP不稳定的问题；
通过信号槽机制实现UI与网络状态同步，让用户体验更流畅。

#### 登录逻辑实现

用户输入账号密码后，客户端会将信息打包并发送给服务器验证。为了提升体验，我加入了超时提示，避免用户长时间等待无反馈。

```cpp
// 登录事件：发送账号密码到服务器，超时显示加载提示
QString data = QString("MY_LOGIN:%1|%2").arg(account).arg(passwd);
socket->write(data.toUtf8());
// 超时1秒显示加载提示
QTimer::singleShot(1000, { ui->label_4->setVisible(true); });
```

功能说明：
登录请求采用自定义协议格式发送，服务器验证通过后返回登录结果；
超时提示让界面更友好，避免用户误以为程序卡顿。

### 二、注册界面

注册界面用于新用户创建账号，包含完整的输入校验与数据提交逻辑，确保注册流程安全规范。

界面包含：
- 账号输入框、密码输入框、确认密码输入框
- 6位数字令牌设置栏（用于找回密码）
- 账号为空、密码为空、密码不一致、令牌格式错误等实时提示
- 确定注册、取消关闭功能按钮

<img src="img/QQ_LITE/zhuce1.png" class="gallery-item">

#### 功能实现：

输入校验逻辑注册功能通过多层校验保证数据合法性，校验通过后才会向服务器发送请求：
1. 账号非空校验：未输入账号时显示提示，阻止提交
2. 密码非空校验：未输入密码时显示提示，阻止提交
3. 两次密码一致性校验：密码不一致时显示提示，阻止提交
4. 令牌格式校验：必须为6位纯数字，否则提示格式错误

所有提示标签默认隐藏，仅在对应错误触发时显示，保证界面简洁。

#### 功能实现：

注册数据提交校验全部通过后，程序将账号、密码、令牌按自定义协议打包，并通过 TCP Socket 发送给服务器完成注册。
发送完成后自动关闭注册窗口，返回登录界面。

```cpp
// 组装注册数据并发送
void Register::sendinformation()
{
    QString data = QString("NEWACCOUNT:%1|%2|%3")
    .arg(account)
    .arg(passwd)
    .arg(token);
    socket->write(data.toUtf8());
    socket->flush();
    this->close();
}
```
